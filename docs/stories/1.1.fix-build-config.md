## Story
**As a** Developer,
**I want** to configure the project build process to use Webpack instead of Turbopack,
**so that** the application can be built successfully despite special characters in the project path.

## Acceptance Criteria
1. The project `next build` command runs successfully without "byte index" errors related to file paths.
2. The `package.json` build script is updated to use the `--webpack` flag.
3. The build output is successfully generated in the `.next` directory.

## Dev Notes
- **Problem**: Turbopack currently fails with non-ASCII characters in file paths (e.g., "Área de Trabalho").
- **Solution**: Webpack handles these paths correctly. Next.js still supports Webpack fully.
- **Reference**: Next.js documentation on `--webpack` flag.
